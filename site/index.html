The finding that shapes Phase 2

17hats only starts a workflow from a pick-from-a-list answer.

17hats can start a different workflow for each answer, but only on a “Choose from a List” question, and only one such question per Lead Capture Form. If the budget question is typed (“$2,500”), every lead gets the same treatment and your $1,200 split never happens. So the investment question is a fixed list, and it is the only question that routes. See the funnel →

Also found on your live site

/contact offers anyone a free 15-minute call

Today's Contact page invites everyone to “Schedule a FREE 15-min discovery call”. Left in place, it bypasses the new qualifying questionnaire. The redirect map sends /contact to /intake, and that Calendly event should be retired or made secret.

Calendly detail

A secret event hides the link; it doesn't gate it

Calendly's “secret” setting removes an event from your public page, but anyone holding the link can still book. Qualified leads get the secret link by email from 17hats. If links start circulating, I rotate the event URL in one click.

Squarespace detail

Moving the store to Not Linked doesn't remove it from Google

Not Linked pages stay public and indexed. The store collection also needs “Hide page from search results”. Product pages can't be hidden one by one, only as the whole collection.

        How each contact was placed

        What the sorter did

          Rules, in plain words

          • A “Vertical” column wins. If a file already says Work, Live or Play, that's used.
          • Otherwise, signals score it: job titles and companies (Work), programs like PQ Bootcamp or burnout webinars (Live), classes like belly dance, MENAHT or Fiercely Feminine (Play), plus the file and sheet names.
          • Close calls aren't guessed. They go to Review with the reason, for you to decide in one pass.
          • An opt-out anywhere wins. If any file marks someone unsubscribed, they're held back. Squarespace's import also expects consent from everyone you add.
          • Bad addresses are rejected with a reason, and typo fixes like gmial.com → gmail.com are suggested, never applied silently.

          Why it matters in Squarespace

          • Mailing-list imports take a .csv with the email in the first column, then first and last name.
          • Someone who unsubscribed in Squarespace isn't resubscribed by re-importing them, so the clean-up has to happen before the first import.
          • Lists with likely bounces can be refused at upload. Rejecting invalid addresses first avoids that.
          • Email Campaigns plans cap monthly sends, so segment sizes decide which plan you need.

          17hats setup sheet

            Connections

            • Gmail: connected in 17hats as both the incoming and the outgoing server. Workflow emails leave from Asali's own address, and replies thread back into the 17hats project. Using the 17hats mail server with a free @gmail.com address is what lands in spam; this avoids it.
            • Calendly: two secret event types, Individual (30 min) and Organizations (45 min). Only the qualified workflows contain those links. The old free 15-minute event is retired or made secret.
            • No Zapier needed for routing: 17hats does it natively. Zapier stays an option for logging Calendly bookings back into 17hats, which needs a paid Calendly plan.
            • Work / Live / Play tag is set from question 1 on every lead, so the same segments feed future email campaigns.
